## Featured Projects

### GreenFraudShield · Detección de fraude

Sistema inteligente de evaluación de riesgo de fraude con IA local. Combina **Autoencoder (PyTorch + CUDA)**, **Isolation Forest** y **XGBoost**, con explicabilidad mediante **LLaMA 3** vía Ollama.

- API dual: FastAPI y Go (Gin) para alto rendimiento.
- Dashboard Streamlit con interfaz de entrenamiento en tiempo real.
- AUC-ROC combinado reportado en el proyecto: **0.93–0.97**.
- Siete patrones de fraude simulados, incluidos *velocity*, *impossible travel* y VPN.

### GreenPOS — Soft Restaurant

Sistema completo de gestión para restaurantes desarrollado con **Flutter y Clean Architecture**. Incluye módulos para clientes y administradores, con diseño responsivo para móviles y tablets.

- Menú por categorías con fotos y carrito en tiempo real.
- Panel administrativo para productos, pedidos, mesas y reservas.
- Autenticación y datos con Firebase; almacenamiento local con SQLite.
- Temas claro y oscuro, Riverpod y GoRouter.
